# Automotive Valuation Analytics 🚗📊
> Aplicação web interativa desenvolvida em Python para análise exploratória e predição de preços de veículos no mercado automotivo.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python
- **Manipulação e Análise de Dados:** Pandas, NumPy
- **Visualização de Dados:** Matplotlib, Seaborn
- **Deploy e Web App:** Render, Streamlit / Flask
- **Controle de Versão:** Git e GitHub

## 🚀 Funcionalidades & Pipeline
- **Limpeza e Tratamento de Dados:** Tratamento de valores ausentes, remoção de duplicadas e engenharia de atributos (*feature engineering*).
- **Análise Exploratória de Dados (EDA):** Identificação de padrões, correlações de mercado e distribuição de preços por quilometragem e ano.
- **Deploy Online:** Aplicação web hospedada e acessível em tempo real para interação com o modelo.
